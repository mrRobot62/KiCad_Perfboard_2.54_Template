BK_Perfboard_2.54

(Version 1.0)


KiCad template for designing and documenting prototype circuits on 2.54 mm perfboard.


The template provides:

- 2.54 mm default grid

- visual perfboard hole grid

- dedicated wire and jumper layers

- Bottom Wire (B.Cu) as the default working layer

- a predefined board outline

- BK_Perf_SolderPoint for explicit solder/junction points


This template is intended for hobby electronics prototyping.

Basic KiCad and electronics knowledge is assumed.
